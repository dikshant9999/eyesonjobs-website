# Eyes on Jobs website

A WordPress theme and companion plugin for eyesonjobs.com: jobs, candidate and employer accounts, resume and enquiry forms with reCAPTCHA v3, and the Job Preparation Package with UPI QR, PayPal and card payments through Razorpay.

| Folder / file | What it is |
| --- | --- |
| `eyesonjobs/` | The theme |
| `eyesonjobs-core/` | The plugin (jobs, forms, accounts, payments) |
| `eyesonjobs-theme.zip`, `eyesonjobs-core.zip` | Ready-to-upload installers (Plugins / Appearance → Add New → Upload) |
| `INSTALL.md` | Step-by-step install guide for the site owner |
| `blueprint.json` | Powers the live preview link below |
